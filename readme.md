PersonaFlow AI: Global Identity Studio

PersonaFlow AI হলো একটি প্রিমিয়াম, আন্তর্জাতিক AI পোর্ট্রেট জেনারেটর অ্যাপ্লিকেশন। এই অ্যাপটি আপনার চেহারা ব্যবহার করে বিশ্বের বিভিন্ন দেশ এবং ১০০+ পেশার বাস্তবসম্মত প্রতিকৃতি (Photorealistic Portraits) তৈরি করতে পারে। এটি বিশেষভাবে বিজ্ঞাপন সংস্থা, ব্র্যান্ডিং এবং কর্পোরেট ব্যবহারের জন্য ডিজাইন করা হয়েছে।

🎯 অ্যাপের গল্প: বিজ্ঞাপন ও ব্র্যান্ডিংয়ের নতুন দিগন্ত

"এক ক্লিকে আপনার চেহারা, বিশ্বের প্রতিটি পেশায়: বিজ্ঞাপন ও ব্র্যান্ডিংয়ের জন্য উচ্চ-মানের চরিত্র তৈরি করুন।"

🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Commercial Features)

এই অ্যাপের সমস্ত ফিচার বাণিজ্যিক বিক্রয়যোগ্যতা এবং সর্বোচ্চ পারফরম্যান্স নিশ্চিত করে।

আন্তর্জাতিক ক্যারেক্টার জেনারেশন: বাংলাদেশ, USA, মধ্যপ্রাচ্য এবং ইউরোপীয় প্রেক্ষাপটে ক্যারেক্টার তৈরির অপশন। (কোডে Country Context Selection হিসেবে যুক্ত)।

উচ্চ রেজোলিউশন আউটপুট: প্রিন্ট মাস্টার (PRO Tier) রেজোলিউশন সহ উচ্চ-গুণমানের JPG ছবি তৈরি (98% Quality), যা প্রিন্ট বিজ্ঞাপনের জন্য উপযুক্ত।

বাস্তবসম্মত নির্ভুলতা (Authenticity Lock): সামরিক ও নিরাপত্তা বাহিনীর ইউনিফর্মের রং, স্টাইল এবং নেমপ্লেট/লোগো বর্জন নীতি কঠোরভাবে অনুসরণ করা হয়েছে।

অ্যাডভান্সড কন্ট্রোল: টোন/মেজাজ, ক্যামেরা অ্যাঙ্গেল (ক্লোজ-আপ, মিডিয়াম শট) এবং Aspect Ratio (4:5, 16:9) নির্বাচনের সুবিধা।

স্থির ডাউনলোড প্রক্রিয়া: ব্রাউজার ব্লক এড়াতে পর্যায়ক্রমিক (Sequential) সব ছবি ডাউনলোড করার সুবিধা।

স্থায়ী গ্যালারি: Firebase Firestore ব্যবহার করে ব্যবহারকারীর তৈরি করা ছবির ইতিহাস সংরক্ষণ।

প্রিমিয়াম ইউএক্স: ড্যাশবোর্ড স্টাইল লেআউট, ইন্টারেক্টিভ বাটন এবং স্মুথ লোডিং অ্যানিমেশন।

🛠️ সেটআপ নির্দেশাবলী (Setup Instructions)

এই প্রোজেক্টটি একটি সিঙ্গেল-ফাইল React অ্যাপ্লিকেশন হিসেবে তৈরি করা হয়েছে। এটি একটি আধুনিক JavaScript পরিবেশে চালানোর জন্য প্রস্তুত।

১. ফাইল ডাউনলোড ও প্রতিস্থাপন

১. CharacterCreator.jsx ফাইলটি ডাউনলোড করুন।
২. আপনার স্থানীয় React প্রোজেক্টের (src/ ফোল্ডারে) এই .jsx ফাইলটি প্রতিস্থাপন করুন।

২. Firebase এবং API কনফিগারেশন

এই অ্যাপটি Firebase (Firestore ও Auth) এবং Google Gemini API ব্যবহার করে। প্রোজেক্টে কিছু গ্লোবাল কনস্ট্যান্ট ব্যবহৃত হয়েছে।

স্থানীয়ভাবে চালানোর জন্য (Locally):

CharacterCreator.jsx ফাইলের শুরুতে নিম্নলিখিত কনস্ট্যান্টগুলি আপনার নিজস্ব ভ্যালু দিয়ে প্রতিস্থাপন করুন:

// --- Global Variables and Libraries ---
// ... অন্যান্য কনস্ট্যান্ট ...
const firebaseConfig = { /* ... আপনার Firebase কনফিগ এখানে দিন ... */ };
const initialAuthToken = null; 
const API_KEY = "YOUR_GEMINI_API_KEY"; // <--- আপনার Gemini API Key এখানে দিন 
// ... অন্যান্য কনস্ট্যান্ট ...


গুরুত্বপূর্ণ: ইমেজ জেনারেশন করতে আপনাকে অবশ্যই একটি বৈধ Gemini API Key ব্যবহার করতে হবে।

🤝 সাবস্ক্রিপশন ও মনিটাইজেশন (Monetization Strategy)

ডিফল্ট টায়ার: কোডটি বর্তমানে 'AGENCY' টায়ারে সেট করা আছে (সমস্ত ফিচার আনলকড), যা বিক্রির জন্য ডেমো হিসেবে কাজ করবে।

সাবস্ক্রিপশন নিয়ন্ত্রণ: USER_TIERS কনস্ট্যান্ট ব্যবহার করে আপনি রেজোলিউশন লক এবং দৈনিক জেনারেশন ক্যাপ নিয়ন্ত্রণ করতে পারবেন।

বিক্রি মডেল: বাণিজ্যিক ব্যবহারের জন্য আল্ট্রা HD বা প্রিন্ট মাস্টার রেজোলিউশন টায়ারগুলোকে আপনার পেমেন্ট গেটওয়ের মাধ্যমে (যেমন bKash, Stripe) লক ও আনলক করতে হবে।

🔒 নিরাপত্তা সতর্কতা

Firebase কনফিগারেশন এবং Auth Token সাধারণত পাবলিক রিপোজিটরিতে রাখা উচিত নয়। গিটহাবে আপলোড করার সময় এনভায়রনমেন্ট ভ্যারিয়েবল (.env ফাইল) ব্যবহার করে এই ডেটাগুলি সুরক্ষিত রাখুন।
